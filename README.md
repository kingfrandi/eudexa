# EUDEXA V1

MVP frontend de una plataforma fintech internacional.

## Ejecutar
npm install
npm run dev

## Incluye
- Homepage responsive
- Conversor demo de divisas
- Mercados demo claramente identificados
- Búsqueda global demo
- Light/Dark mode persistente
- Español/Inglés
- Calculadora flotante
- Secciones de educación y espacios AdSlot

Los datos actuales son DEMO y no representan cotizaciones en tiempo real.
